# SpendWise

SpendWise is a modern personal expense tracker built with React, Vite, and Tailwind CSS.

It helps users record expenses, organize spending by category, monitor budgets, and understand their monthly financial habits.

## Features

- Dashboard with spending overview
- Add, edit, and delete expenses
- Expense filtering and search
- Category-based spending breakdown
- Monthly spending chart
- Budget progress tracking
- Local storage persistence
- Light and dark theme support
- Responsive desktop and mobile layout

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Lucide React
- Recharts
- Local Storage
