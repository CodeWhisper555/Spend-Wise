# SpendWise — Modern Personal Expense Tracker

SpendWise is a modern personal expense tracker built with React, Vite, and Tailwind CSS . It helps users record expenses, organize spending by category, monitor budgets, and understand their monthly financial habits . Additionally, it features a customizable monthly budget (defaulting to ₹50,000) managed through the settings menu, along with seamless light and dark theme persistence.

## ✨ Key Features

- **Dashboard with spending overview**
- **Customizable Monthly Budget**: Set and personalize your target monthly spending limit (defaulting to ₹50,000) directly from the Settings menu.
- **Add, edit, and delete expenses**
- **Expense filtering and search**
- **Category-based spending breakdown**
- **Monthly spending chart** 
- **Budget progress tracking** 
- **Local storage persistence** 
- **Light and dark theme support** 
- **Responsive desktop and mobile layout** 

## 🛠️ Tech Stack

- **React** 
- **Vite** 
- **React Router** 
- **Tailwind CSS** 
- **Lucide React** 
- **Recharts** 
- **Local Storage**
